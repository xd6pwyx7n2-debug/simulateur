Comment fonctionne le calcul ?

L'indemnité légale de licenciement dépend principalement du salaire de référence et de l'ancienneté du salarié.

1. Le salaire de référence

Le simulateur calcule deux moyennes :

  • la rémunération brute totale des 12 derniers mois divisée par 12 ;
  • la rémunération brute totale des 3 derniers mois divisée par 3.

Le montant le plus favorable est retenu pour l'estimation.

2. L'ancienneté

Le calcul prend en compte les années complètes ainsi que les mois supplémentaires renseignés.

3. Une convention collective peut être plus favorable

Le résultat affiché correspond à une estimation fondée sur l'indemnité légale. Votre convention collective ou votre contrat de travail peut prévoir une indemnité plus favorable.

Pour une situation particulière, notamment en cas de rémunération variable, arrêt de travail, temps partiel ou primes importantes, vérifiez les règles applicables à votre situation.

À retenir

  • Le résultat est une estimation, pas un montant juridiquement définitif.
  • La convention collective peut être plus favorable.
  • Les éléments de rémunération entrant dans le salaire de référence doivent être appréciés selon leur nature.
  • Le calcul peut différer dans certaines situations particulières.

Pour vérifier votre situation, consultez les informations officielles disponibles sur Service-Public.fr et le Code du travail numérique .
