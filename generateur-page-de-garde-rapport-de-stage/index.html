Questions fréquentes

Le générateur de page de garde est-il gratuit ?

Oui, sans inscription ni filigrane. La page est composée dans votre navigateur : vos informations et vos logos ne sont pas envoyés à SimuDroit et ne sont mémorisés sur votre appareil que si vous le demandez.

Comment ajouter le logo de l'entreprise ?

Dans la section « Logos », choisissez une image PNG, JPEG ou WebP : elle apparaît tout de suite sur la page de garde. Demandez d'abord l'accord de votre tuteur pour utiliser le logo de l'entreprise.

Ma page de garde respecte-t-elle les consignes de mon établissement ?

Pas forcément : certains établissements imposent un modèle. Le générateur propose une mise en page courante ; vérifiez vos consignes et adaptez le contenu si besoin.

Comment enregistrer la page de garde en PDF ?

Cliquez sur « Télécharger en PDF » : la fenêtre d'impression s'ouvre. Choisissez « Enregistrer au format PDF » comme imprimante (sur iPhone, utilisez le bouton Partager).

Puis-je modifier la page de garde dans Word ?

Oui : le fichier .docx contient le texte et les logos, que vous pouvez ajuster. Les styles colorés de l'aperçu sont simplifiés dans le fichier Word.
