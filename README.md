# SimuDroit

Simulateurs gratuits de droits et de salaire (brut/net, chômage, indemnités, congés payés, heures supplémentaires, etc.).

Site statique (HTML/CSS/JS sans dépendance), publié avec GitHub Pages : https://xd6pwyx7n2-debug.github.io/simulateur/

## Structure

- `index.html` : page d'accueil et liste des simulateurs
- `simulateur-*/index.html` : un dossier par simulateur
- `methode-et-sources/` : formules utilisées et sources officielles
- `404.html`, `sitemap.xml`, `robots.txt`

Les résultats sont des estimations indicatives, sans valeur juridique.
