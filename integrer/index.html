Intégrer un simulateur sur votre site

Ajoutez un simulateur SimuDroit à votre site, blog ou intranet en collant une ligne de code.

Comment faire

Copiez le code de l'iframe du simulateur voulu et collez-le dans votre page. Le paramètre ?embed=1 masque l'en-tête et le pied de page pour ne garder que le simulateur. L'intégration est gratuite ; merci de conserver le lien « Source : SimuDroit » sous l'iframe.
